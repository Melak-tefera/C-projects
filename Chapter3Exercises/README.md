# Chapter 3 – C# OOP Exercises (1–16)

Each exercise is a separate .NET 10 console project. Open this folder in VS Code, open the terminal, then enter the exercise folder you want to run.

Example:
```bash
cd Exercise01
dotnet run
```

For another exercise, return to the parent folder (`cd ..`) and enter its folder, for example `cd Exercise13`, then run `dotnet run`.

Each project has its own `Program.cs` containing its `Main` method. Do not combine all 16 folders into one C# project, because each exercise has a separate entry point.
